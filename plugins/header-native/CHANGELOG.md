# Changelog

## 1.0.4

- Keep tab docking previews above native browser pages during dragging and restore the browser layer after cancellation or placement.

## 1.0.3

- Add a visual layout picker and drag previews for placing tabs left, right, above, or below another tab.
- Correct bottom-edge drops that previously placed a terminal beside the editor.
- Add Open Below and Open Terminal Below actions to file tabs, and preserve unsaved editor buffers when rearranging them.
- Cancel tab dragging with Escape and keep the active pane reflected in the header.

## 1.0.2

- Use the packaged Termco branding icon in Activity notifications, with a visible fallback if the image is unavailable.

## 1.0.1

- Marked rig-switcher floating UI as an application overlay above live browser tabs.
