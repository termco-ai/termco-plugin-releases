# Termco Product Stories

Composes feature-owned semantic targets into replayable end-to-end stories: first value, a project moving from local work to remote operation, and plugin customization through company-profile handoff.

It owns orchestration only. Chat, Agents, Models, Plugins, Profiles, rigs, Containers, Workflows, and coding agents own their focused journeys and target implementations. The onboarding engine and UI remain independently replaceable.
